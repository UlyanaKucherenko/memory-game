# Memory Game

## Description
A browser-based card memory game.

The goal is to find 8 matching pairs of cards in the fewest moves possible. 
The game tracks your moves, announces victory in a modal window, and saves the top 10 best scores.

## Local Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/UlyanaKucherenko/memory-game.git
   cd memory-game
   ```

2. Run a local server (choose either option):
   - **VS Code:** right-click `index.html` - **«Open with Live Server»**.
   - **Node.js:** run `npx serve .` in the terminal.
